Modification notes
Scorebar — clock slot fixed at 56 px (CLOCK_SLOT_W). If you show added time (e.g. 90+4) this overflows. Consider widening to 68 px or using a monospace font.

Scorebar border-radius — currently 6 px (SCOREBAR_RADIUS). Larger teams' names may make the pill very wide. A right-side cutoff with ellipsis would help on narrow canvases.

Event banner Y position — positioned at SCOREBAR_Y + SCOREBAR_H + 8 = 56 px. If a lineup is showing at the same time as a goal, the banner overlaps the top-left corner of the field. Consider moving the banner to the bottom-right during lineup slots.

Lineup — player font size 11 px — at 1280×720 player names longer than ~8 chars are truncated to "F. Surname". This is intentional but worth confirming with your content.

Lineup — subs table row height 38 px — 7 subs = 266 px + 50 px header = 316 px total. With an 11-player starting XI the table fits. If you show 9 subs the table height reaches 392 px and may clip on small canvases.

OverlayPalette — solid RGB only, no alpha — intentional design decision for broadcast colour accuracy. Semi-transparent elements in the preview above simulate the feel; actual Java rendering uses solid fills with darker panel colours for depth.
